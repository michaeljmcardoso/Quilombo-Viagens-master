## 📋 Sobre o Projeto

O **QuilomboViagens** é um sistema desenvolvido para gerenciar o cadastramento de viagens e elaboração de orçamentos para a Divisão Quilombola. A ferramenta permite o registro completo de informações sobre deslocamentos, cálculo automático de custos com diárias e combustível, além de gerar relatórios e análises gráficas.

---

## ✨ Funcionalidades

- ✅ **Cadastro completo de viagens** com todos os campos necessários
- ✅ **Cálculo automático de orçamento** (diárias + combustível)
- ✅ **Seleção de período** via calendário interativo
- ✅ **Visualização em tabela** de todas as viagens cadastradas
- ✅ **Gráficos interativos** para análise de dados
- ✅ **Exportação de relatórios** em formato CSV
- ✅ **Métricas resumidas** em tempo real
- ✅ **Interface amigável** e responsiva

---

## 🛠️ Tecnologias Utilizadas

- **Python 3.8+**
- **Streamlit** - Framework para criação da interface web
- **Pandas** - Manipulação e análise de dados
- **Plotly** - Geração de gráficos interativos
